# Automated Analysis Export & Stakeholder File Guide

## Executive Overview
This document serves as the comprehensive user guide and technical documentation for automated multi-format report exports generated by our analytics pipeline. By automating exports into CSV, PDF, and HTML formats, stakeholders receive self-service access to raw datasets, executive briefs, and interactive visualisations without manual analyst intervention.

---

## 1. Export Deliverables & File Catalog

Every automated export run creates a timestamped folder (e.g., `output/2026-08-13_1350_analysis/`) containing four core artifacts:

| Filename | Format | Target Audience | Primary Use Case | Refresh Schedule |
| :--- | :--- | :--- | :--- | :--- |
| **`cleaned_data.csv`** | Raw CSV | Data Analysts, Financial Planners | Self-service Excel analysis, custom pivot tables, and VLOOKUP modeling. | Daily at 5:00 PM / On-Demand |
| **`summary_report.pdf`** | PDF Document | Executives, Board Members, VPs | Printable executive summary for meetings, iPad review, and email attachments. | Daily at 5:00 PM / On-Demand |
| **`interactive_report.html`** | Standalone HTML | Business Partners, Product Managers | Interactive browser exploration (zoom, pan, hover tooltips) with zero installation required. | Daily at 5:00 PM / On-Demand |
| **`README.md`** | Markdown Text | Audit & Governance Teams | Data lineage tracking, record counts, execution timestamps, and column schemas. | Generated with each run |

---

## 2. Stakeholder User Guide: How to Use Each Artifact

### 1. For Excel Analysis (`cleaned_data.csv`)
- **How to Open**: Double-click to open directly in Microsoft Excel, Google Sheets, or PowerBI.
- **Content**: Validated dataset containing all cleaned customer and transaction features (`order_id`, `order_date`, `product_line`, `region`, `amount`).
- **Best For**: Financial modeling, ad-hoc cohort filtering, and creating custom summary pivot tables.

### 2. For Meetings & C-Suite Briefings (`summary_report.pdf`)
- **How to Open**: Open in Adobe Acrobat, Apple Preview, or any web browser.
- **Content**: 1-to-2 page executive brief containing the Situation, Key Findings, Quantified Business Risks, Actionable Recommendations, and Decision Requests.
- **Best For**: Board decks, executive status checks, and email updates.

### 3. For Interactive Data Exploration (`interactive_report.html`)
- **How to Open**: Double-click to open in Google Chrome, Microsoft Edge, Safari, or Firefox.
- **Content**: Complete executive narrative integrated with embedded, responsive Plotly charts.
- **Features**:
  - **Hover Tooltips**: Reveal exact daily revenue, order counts, and growth metrics.
  - **Zoom & Pan**: Click and drag across date ranges or metric axes to inspect specific periods.
  - **Zero Dependencies**: Includes Plotly CDN script tag; runs on any computer without Python or software installations.

## 3. Automation, Scheduling & Error Handling

### Scheduled Execution (`export_functions.py`)
Automated report exports are scheduled using Python's `schedule` engine (or Linux `cron` / Windows Task Scheduler):
```python
import schedule
import time

# Schedule daily export run at 5:00 PM
schedule.every().day.at("17:00").do(scheduled_export_job)

while True:
    schedule.run_pending()
    time.sleep(60)
```

### Error Handling & Resilience Protocol
1. **Graceful Degradation**: If one format export fails (e.g. PDF font rendering error), the pipeline catches the exception, logs details, and continues exporting CSV and HTML artifacts.
2. **Execution Logging**: All automated runs log timestamps, record counts, file sizes, and status codes to `output/export_execution.log`.
3. **Data Team Alerting**: Failed exports trigger immediate notification alerts to the data engineering team while serving cached prior reports to stakeholders.

## 4. Answer to Follow-Up Question: Automated Email Delivery Strategy

### Question:
*How would you automate email delivery of generated reports to executive stakeholders?*

### Solution & Technical Implementation:

To transition from passive downloads to proactive insight delivery, integrate an automated SMTP/SendGrid email dispatch module directly into the post-export callback of `export_analysis()`.

```python
import smtplib
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.application import MIMEApplication

def send_automated_report_email(recipient_emails, report_dir, summary_text):
    """Sends automated email with report summary and PDF/HTML attachments."""
    sender_email = "analytics-reports@company.com"
    subject = f"📊 Daily Executive Churn & Sales Report — {datetime.now().strftime('%b %d, %Y')}"
    
    msg = MIMEMultipart('alternative')
    msg['Subject'] = subject
    msg['From'] = sender_email
    msg['To'] = ", ".join(recipient_emails)
    
    # HTML Body with executive summary and dashboard link
    html_body = f"""
    <html>
    <body style="font-family: Arial, sans-serif;">
        <h2 style="color: #1f77b4;">Executive Insight Briefing</h2>
        <div style="background: #f0f7ff; padding: 15px; border-left: 4px solid #1f77b4;">
            {markdown_to_html(summary_text)}
        </div>
        <p><strong>Download Full Reports:</strong> Attached to this email are the printable PDF brief and raw CSV dataset.</p>
        <p><a href="https://dashboard.company.com" style="background: #1f77b4; color: #fff; padding: 10px 15px; text-decoration: none; border-radius: 4px;">Open Live Streamlit Dashboard</a></p>
    </body>
    </html>
    """
    msg.attach(MIMEText(html_body, 'html'))
    
    # Attach PDF Report
    pdf_path = os.path.join(report_dir, "summary_report.pdf")
    if os.path.exists(pdf_path):
        with open(pdf_path, "rb") as f:
            attach_pdf = MIMEApplication(f.read(), _subtype="pdf")
            attach_pdf.add_header('Content-Disposition', 'attachment', filename="Executive_Summary_Report.pdf")
            msg.attach(attach_pdf)
            
    # Send via SMTP Server
    with smtplib.SMTP('smtp.company.com', 587) as server:
        server.starttls()
        server.login("smtp_user", "smtp_password")
        server.sendmail(sender_email, recipient_emails, msg.as_string())
        
    print(f"✓ Automated email report successfully dispatched to {len(recipient_emails)} recipients.")
```

### Key Benefits of Email Automation:
- **Proactive Delivery**: Delivers key findings directly to executive inboxes at 5:00 PM daily.
- **Zero Friction**: Executive reads the 3-minute summary in email HTML on mobile without logging into dashboards.
- **Attached Deliverables**: PDF and CSV files are pre-attached for offline reading or board distribution.
